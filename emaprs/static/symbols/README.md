# APRS symbol graphics

These sprite sheets come from the aprs.fi high-resolution APRS symbol set by
Heikki Hannikainen, OH7LZB: https://github.com/hessu/aprs-symbols
(commit f2286a9cd43eb6ba4501250b4c39fff111e3796c).

- `aprs-symbols-24-0@2x.png`: primary table (`/`)
- `aprs-symbols-24-1@2x.png`: alternate table (`\` and overlays)
- `aprs-symbols-24-2@2x.png`: overlay characters

Each sheet is 16 columns x 6 rows of 48x48 px symbols (shown at 24x24).
A symbol's index is its character code minus 33 (`!`).

Licensing differs per symbol; see `COPYRIGHT.md` (copied from the upstream
repository unchanged).
